# Multi-core study

Rules for the bottleneck label (applied in order, INFERRED): DRAM traffic >= 70% of the measured ceiling for that core count -> memory bandwidth; OpenMP runtime >= 30% of samples -> synchronisation / too little parallel work; unhalted fraction < 70% -> idle cores; streams slowed >= 10% vs alone -> shared L3/DRAM contention; cycles stalled on L3 misses >= 20% -> memory latency; FLOP rate >= 55% of peak per busy cycle -> compute; otherwise kernel inefficiency / mixed.
